## Deployment blocker from current Render logs

The current Render health endpoint returns HTTP 200 but omits the source's `revision` field; its curated OpenAPI document lacks current subscription paths, and unauthenticated developer-key access returns 200 rather than source-required 401. Treat the API as stale until Render reports the expected commit SHA and passes the auth smoke check. No Render CLI, API token, deploy hook, or dashboard session is available in this workspace. When configuring the service, set `STORAGE_DRIVER=supabase`, the HTTPS project `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, and an existing private `SUPABASE_STORAGE_BUCKET`; never expose the service-role key to the browser or commit it. Customer upload quotas default to 30 per IP per minute and 1,000 per IP per UTC day and can be adjusted with `PUBLIC_UPLOADS_PER_MINUTE` and `PUBLIC_UPLOADS_PER_DAY`.
